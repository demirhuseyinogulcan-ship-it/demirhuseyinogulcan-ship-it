# Can Demir

I build online stores and connect them to the systems behind the business: ERP, payments, shipping and invoicing. I work under the name [commitius](https://commitius.com), a small studio based in Istanbul.

Day to day I run an Odoo ERP with Medusa and Next.js storefronts for an industrial supplier, so most of what I write here has been tested against real orders.

## What I work with

- **Commerce:** Next.js, Medusa, WooCommerce, Shopify
- **ERP:** Odoo, ERPNext
- **Integrations:** payment gateways, shipping APIs, e-invoicing, Google Merchant Center
- **Web:** TypeScript, React, Tailwind CSS, PostgreSQL, SEO and Core Web Vitals
- **Mobile:** Flutter
